
# Framework para Desenvolvimento de Software

## 📚 Sobre o Projeto

Este repositório contém o desenvolvimento de atividades práticas e projetos da disciplina **Framework para Desenvolvimento de Software**.

O objetivo da disciplina é aplicar conceitos de desenvolvimento de aplicações por meio da utilização de frameworks modernos, explorando recursos de persistência de dados, arquitetura de software, interface gráfica, integração com bancos de dados e boas práticas de programação.

---

## 🎯 Objetivo

Desenvolver aplicações utilizando frameworks que possibilitem:

- Aumento da produtividade no desenvolvimento;
- Reutilização de componentes;
- Padronização da arquitetura do projeto;
- Facilidade de manutenção e evolução do software;
- Integração com bancos de dados e serviços externos.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- Java
- Android Studio
- Android SDK
- SQLite
- XML para construção de interfaces
- Git
- GitHub

## ⚙️ Funcionalidades

O sistema permite:

- Cadastro de produtos;
- Validação dos dados informados;
- Armazenamento em banco de dados SQLite;
- Listagem dos produtos cadastrados;
- Persistência local dos dados;
- Interface intuitiva para interação do usuário.

---

## 💾 Banco de Dados

O projeto utiliza o banco de dados SQLite embarcado no Android.

### Tabela: Produtos

| Campo | Tipo | Descrição |
|---------|---------|---------|
| _id | INTEGER | Chave primária |
| nome | TEXT | Nome do produto |
| preco | REAL | Preço do produto |

## 🚀 Execução do Projeto

1. Clone este repositório:

```bash
git clone https://github.com/seuusuario/seurepositorio.git
```

2. Abra o projeto no Android Studio.

3. Aguarde a sincronização do Gradle.

4. Execute o projeto em um dispositivo físico ou emulador Android.
